## Reproduce and limits

Run `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v` on Python 3.11+ in a POSIX environment. For live routing, explicitly install native MCP, the reviewed named tool trust and session gate from the README, open a new Codex chat in a disposable project, and request a sole-file README/code edit or a cross-module parser/codec contract. Verify actual native call order and project-tree changes; do not infer triggering from a final answer alone.

Automatic routing depends on model compliance and host permissions. It is not a forced hook, background monitor, Google-supported product or paper benchmark reproduction. Runtime tool calls do not automatically change user policy. Configuration updates use a last-moment content check plus atomic replacement; they cannot provide an atomic compare-and-swap against all unrelated concurrent editors.
